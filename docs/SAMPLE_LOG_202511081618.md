## Interpretation (medium confidence)
A failed motor/prop shows the controller driving one side to max **before** the attitude is lost.
Here the controller output stayed small while the model tipped, so a motor/prop failure is less
likely than (1) an attitude that was commanded (outer loop / mode / RC / failsafe), or (2) a control
software fault. This log has no attitude setpoint or RC/mode channel, so it cannot be proven from
this file. Ask the vendor to log attitude setpoint, RC input and flight mode.

- Motor numbering in the log does not match the stated layout (see RLOG_FORMAT.md).
